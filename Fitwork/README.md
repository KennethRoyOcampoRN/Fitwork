# FITWORK — Employee Medical Records System

This is the `main` branch placeholder. FITWORK is an on-premise employee
medical records system for a single industrial/occupational-health clinic,
built per the MVP build specification.

Development happens on feature branches (one per build phase), each opened
as its own pull request against `main` for review before merging. See the
open pull request for the current state of the build (Phases 1-3: auth/RBAC,
employee records, and clinical notes with immutability enforcement).
